Call `mozg_map`.

The tool answers in English. Give the user the picture in your own words, in the language the user writes to you in: which modules are theirs, which they have not explained, which the agent has rewritten since they were explained, and where the agent should be asking before it changes things. Keep it to a short list; the tool's text is the source, not the script.

If anything is waiting, offer to run an explain-back.
