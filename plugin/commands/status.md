Call `mozg_status`.

The tool answers in English. Tell the user, in a few sentences, in your own words and in the language the user writes to you in: what they own today, what the agent changed, what is worth explaining, and the streak. Do not read the tool's text back word for word, and do not add numbers the tool did not give.

If something is worth explaining, offer to run an explain-back. One round takes about a minute.
